# 0.3.50 — keep the player off the official client's map edge

The length-97 PU is a legal Haxe `toData` line (holder 9134869, display 19, baby -9134870, birth-relative -4,-34). The official client still crashes beside the loaded-map edge: `isBadBiome` and the floor draw index off the 64×64 RAM map when the camera is within a few tiles of that edge.

Haxe `p.x` stays continuous across the world seam. A `rem_euclid` of the step from 0 to -1 stores `width-1`. The next map chunk is then centered a full map away, so the player is left standing on that edge without having crossed it.

One-tile hops (unstuck, push, pull, drop-from-arms) now keep the continuous tile. Before a map chunk or player update, a position that is the same neighborhood as the last chunk is rewritten into that chunk's numbers. A MOVE whose start is the client's tile across the seam is rebuilt there, not as a path the long way around the torus.

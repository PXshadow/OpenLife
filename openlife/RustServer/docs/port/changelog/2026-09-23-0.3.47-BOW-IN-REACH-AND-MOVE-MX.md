# 0.3.48 — bow in reach, animal move MX, path loops

0.3.47 (`f2860fdf`) already picked the closer arrow ingredient. This build is the craft search and the protocol fixes.

CraftItem(152) now treats a Yew Bow already inside the full search as the existing half of arrow + bow. The next step is the missing arrow (134+140 when those are the ready pair), not another rope + yew shaft and not flint on the bow.

Penguin and seal time-moves send Haxe `SendAnimalMoveUpdate`: destination `x y floor id -1 old_x old_y speed`, then the origin clear. A short placement was what the official client logged as "New placement".

Player PM paths drop a repeated cell before the walk is sent. The official client was printing "Removing loop" and can index `pathToDest[-1]` if that removal leaves a single point.

Arrow-chain steps that are all possible pick the closer pair, so a held thread uses a nearby skewer instead of a far sharp stone.

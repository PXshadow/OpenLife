# 0.3.43 — time transitions for graves and bare trees

Haxe `DoWorldMapTimeStuff` walks each map band and arms `timeToChange` on any object with a `-1` transition. Fresh Grave 87 becomes Grave 88 after about 120 seconds, then Old Grave, then nothing. Bare Yew Tree 406 uses `autoDecaySeconds -1`, which is one hour, then grows back into Yew Tree with a branch.

Rust only decayed objects that had been put on an explicit timer, and it ignored negative hour values. Graves placed at death never got a timer, so fresh graves stayed. Bare trees never grew a branch back. The map band now arms those clocks, and a negative decay time is treated as hours.

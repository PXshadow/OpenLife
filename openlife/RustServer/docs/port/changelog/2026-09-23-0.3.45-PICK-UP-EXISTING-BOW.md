# 0.3.45 — pick up an existing yew bow before making another

Haxe `GetOrCraftItem(152)` looks for a bow and arrow, then crafts one. The craft's actor is the yew bow (151) plus an arrow. The live map already has many yew bows and no arrows. `getWeapon` was still walking to rope and a yew shaft, so it made another bow and never started the arrow.

Empty hands now pick up a bow and arrow if one is in range, otherwise an existing yew bow. The next think, holding that bow, seeks the missing arrow. Rope plus shaft is only used when no bow is in range.

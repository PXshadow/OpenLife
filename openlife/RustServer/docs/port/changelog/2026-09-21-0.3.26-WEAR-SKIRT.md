# 0.3.26 — pick up Reed Skirt and wear it

Heartbeat: 2026-09-21T21:20:00Z

Haxe `isPickingupCloths` only sees clothes inside 8 tiles. `craftClothIfNeeded(128)` was stopping on a closer milkweed step, so rope+reed inside 60 never ran and the ground skirt stayed unworn.

Clothing `CraftItem(128)` now:
- DROP-picks an existing 128 within 60 of the player or home (`isDropingItem`, then `switchCloths` SELF).
- Otherwise, if rope 59 and reed bundle 124 are both inside that 60, pick up the rope or USE it on the bundle. That places 128 at their feet for the next pickup.

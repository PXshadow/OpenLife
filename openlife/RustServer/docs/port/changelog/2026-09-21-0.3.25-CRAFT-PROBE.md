# 0.3.25 — searchCurrentPosition on; secret craft probe

Heartbeat: 2026-09-21T20:40:00Z

Clothing and the shared craft state search the player’s current tile as well as home (`searchCurrentPosition = true`). Radius still steps by 30 up to 60.

`GET /api/craft/probe?x=&y=&id=&radius=` returns whether that id is craftable there and the actor and target tiles. Auth is header `X-OpenLife-Secret` or `Authorization: Bearer`, equal to `server.toml` `secret`. The value is not logged.

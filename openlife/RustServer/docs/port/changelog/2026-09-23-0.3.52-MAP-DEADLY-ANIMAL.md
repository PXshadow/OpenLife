# 0.3.52 — deadly animals are map objects

Haxe `GetCloseDeadlyAnimalHelper` scans map tiles in a half-open square, then keeps an animal only when `dist <= moves²`. The mover list was empty, so a wolf on the map never counted, and a snake inside Chebyshev 6 but outside that distance replaced the home wolf.

The hunt now reads the map with that same test, including the loved-biome skip. A far snake no longer takes the bow target away from a closer wolf.

## How we work a chunk (efficient / automatic)

1. Read Haxe `AiBase.hx` lines `(done+1) ..= (done+chunk_size)`.  
2. List every **executable** statement (skip comments / commented-out `craftItem` tests).  
3. Grep Rust for the Haxe anchor (`// Haxe: AiBase.… Lnnn`) or the function name.  
4. For each item: **IN** (present + tested), **PARTIAL**, or **MISSING**.  
5. Implement **MISSING** / close **PARTIAL** against Haxe (same file, same lines).  
6. Run targeted `cargo test` (`ol-ai-helper`, `ol-server --bin ol-server npc_ai`).  
7. Append a log row; move the pointer; print:

```text
AiBase.hx  done_through=N  next=N+1..=N+400  gaps_closed=…  remaining=…
```

**Machine pointer:** [AIBASE_POINTER.json](AIBASE_POINTER.json) (`done_through_line`). JSON wins if MD disagrees.

**Resume until the file is done:** 100-line hops from [AIBASE_POINTER.json](AIBASE_POINTER.json).

```text
/workflow aibase-line-chunk
args: { "mode": "implement", "max_chunks": 1 }
```

- Reads `done_through_line` → next **100** Haxe lines → audit vs Rust → implement → tests.  
- Advances the pointer **only** if remaining_gaps is empty and tests_ok.  
- Stops when `done_through_line >= haxe_total_lines` (9433).  
- A durable 5-minute dispatcher: **skip** if a hop is still running; **resume_from `last_hop_agent_id`** if the last hop finished and the file is not done; **fresh hop** only if resume hits the transcript cap.  
- Reports: `AiBase.hx done_through=N next=A..=B advanced=true|false`  
- `max_chunks` 1–4 hops in one run; stops early if a chunk still has gaps.

Script: `openlife/RustServer/.grok/workflows/aibase-line-chunk.rhai` (also `~/.grok/workflows/aibase-line-chunk.rhai`).

The agent **must** read this pointer first, then only that line range. Do not skip ahead. Do not invent MOVE/goto rules: Haxe `if (isMoving()) return true` then `gotoObj` only when stopped, or when the destination changed.

**MOVE rule (Haxe, not invented):**

- `MoveHelper.isMoveing()` = `newMoves != null` (`MoveHelper.hx` L65).  
- `isUsingItem` / `isDropingItem` / `GetOrCraftItem`: `if (myPlayer.isMoving()) return true;` — **no new MOVE**.  
- Send MOVE only if **arrived** (`!isMoving()`) **or** the **target changed** (e.g. `isMovingToPlayer` still `gotoAdv` because the follow tile moved).  
- Rust: `npc_should_send_move` in `npc_ai.rs`.
